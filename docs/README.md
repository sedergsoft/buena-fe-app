# Documentación del proyecto

Esta carpeta concentra la documentación funcional y técnica de Buena Fe.

## Documentos previstos

- `project-charter.md`: propósito, alcance y objetivos.
- `requirements.md`: requisitos funcionales y no funcionales.
- `architecture.md`: arquitectura lógica y componentes.
- `data-model.md`: modelo conceptual y físico de datos.
- `api-contract.md`: contrato de la API REST.
- `development-plan.md`: plan de desarrollo por tareas.
- `decisions/`: registros de decisiones de arquitectura (ADR).

Los documentos se incorporarán y validarán progresivamente antes de implementar cada componente.
