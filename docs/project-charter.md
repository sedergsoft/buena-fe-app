# Acta de constitución del proyecto — Buena Fe

## Propósito

Crear una plataforma digital y una aplicación móvil que organicen y faciliten el acceso a información sobre la trayectoria artística del grupo musical cubano Buena Fe.

## Objetivo general

Desarrollar una aplicación Android respaldada por una API REST y un panel de administración, que permita consultar biografía, integrantes, discografía, canciones, noticias, conciertos y contenido multimedia autorizado.

## Alcance del MVP

- Inicio con contenidos destacados.
- Historia y biografía del grupo.
- Discografía y fichas de álbumes.
- Catálogo de canciones y búsqueda.
- Noticias.
- Calendario de conciertos.
- Galería de material autorizado y enlaces externos.
- Favoritos almacenados localmente.
- Panel administrativo para gestionar contenidos.

## Fuera del alcance inicial

- Red social y comentarios de usuarios.
- Suscripciones y pagos.
- Tienda de merchandising.
- Venta o reventa de entradas.
- Alojamiento o reproducción de grabaciones protegidas sin licencia.

## Plataformas y tecnologías previstas

- Android: Kotlin, Jetpack Compose y MVVM.
- Backend y panel: PHP con Yii2.
- Persistencia: MySQL.
- Comunicación: API REST sobre HTTPS en producción.

## Condiciones y riesgos

- La publicación de nombre, imagen, logotipos, fotografías, letras, audio y vídeo debe respetar los derechos y autorizaciones aplicables.
- La información biográfica y discográfica deberá contrastarse con fuentes fiables.
- Las integraciones externas dependerán de las condiciones y disponibilidad de cada plataforma.

## Entregables principales

1. Aplicación Android.
2. Backend/API REST.
3. Panel de administración.
4. Esquema de base de datos y migraciones.
5. Documentación técnica.
6. Pruebas e instrucciones de instalación y operación.
